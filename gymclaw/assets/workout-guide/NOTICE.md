# Workout Guide assets

Source: https://github.com/bryllim/workout-guide
Commit: aac599224bb9780305239607ef98540b7e0ce389

GymClaw bundles first-pose artwork for all 302 exercises.
SVG files are unmodified. Dashboard CSS inverts their white artwork on light backgrounds.
PNG files are 1024 px renders of the SVGs with an opaque black background for contrast in Telegram
chat themes. `animation.gif` files are 1024 px loops of upstream frames 1, 2, 3, 2 (350 ms each) on the
same background. Both come from `scripts/render-illustrations`. Chat captions carry no credit line;
attribution lives here and in the README.
GymClaw made these presentation changes. Adapted PNGs and GIFs remain CC BY-SA 4.0.
The upstream manifest retains per-frame attribution and recorded Everkinetic adaptations.
Frame 1 SVGs are bundled; frames 2 and 3 are only bundled inside the GIFs.

Visual assets are CC BY-SA 4.0. Upstream code and metadata are MIT.
